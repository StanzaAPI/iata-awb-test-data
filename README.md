# IATA Air Waybill Test Data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23076186.svg)](https://doi.org/10.5281/zenodo.23076186)

Air waybill numbers combining a 3-digit airline prefix, a 7-digit serial, and a MOD-7 check digit (IATA Resolution 600a).

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

DOI: [10.5281/zenodo.23076186](https://doi.org/10.5281/zenodo.23076186)

## Files

- `iata-awb-small.json`
- `iata-awb-small.csv`
- `iata-awb-medium.json`
- `iata-awb-medium.csv`
- `iata-awb-large.json`
- `iata-awb-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
